    * Intinya Pagination adalah teknik untuk membuat agar website yang menampilkan data masif bisa membatasinya
    agar load browser lebih enteng dan hemat resource terutama RAM
    dimana main Key untuk feature ini adalah pada keyword sql yaitu LIMIT, yaitu untuk me-LIMIT/membatasi data yang di select
        jadi keyword sql LIMIT khusus untuk query SELECT dan sangat cocok
    
    dimana tekniknya sederhana, cuman butuh konfigurasi variabel dan GET value via anchor
    intinya rumus untuk menentukan jumlah halaman nya:
        jumlah halaman = total data perhalaman : total data dari database


|| Fungsi baru, terkait manipulasi nilai float/desimal:
    - round() -> mencari nilai terdekat, jika kurang dari 1.5 akan ke bawah, jika lebih akan ke atas 
        misal : $x = 1.3 ->result = 1; or $x = 1.5 ->result = 2;
    - floor() -> akan membulatkan ke bilangan di bawahnya, misal float 1.9, result = 1 [key = floor artinya lantai, lantai->bagian bawah]
    - ceil() -> ceil artinya langit/bagian atas, berarti kebalikan dari mekanisme floor()
